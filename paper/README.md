# Paper folder

`main.tex` is the manuscript skeleton. It follows the writing rules used in this
project: American English, passive voice, no semicolons, no em dashes, no bold
or itemized lists inside the main sections, and an external BibTeX file.

## Build

```bash
latexmk -pdf main.tex        # or upload the folder to Overleaf
```

## Tables and figures

The results table is generated by the aggregation step, so the paper never
contains hand-copied numbers:

```bash
.venv/bin/python -m code.aggregate --results results/experiment.jsonl --out results/tables
```

Include it into the manuscript with:

```latex
\input{../results/tables/summary.tex}
```

## Bibliography

`refs.bib` holds only entries that were verified against a public record. Do not
add a citation that cannot be resolved to an arXiv identifier, a DOI or a
publisher page. Placeholder text in the skeleton marks the citation slots of the
Related Work section.
